# ヘルプの図を撮る道具

使い方ガイド（`docs/manual.html`）に載っている図を、まとめて撮り直すための道具です。

```
node tools/figs/all.js
```

これだけで36枚を撮り直し、`docs/img/` の JPG を差し替えます。
一部だけ撮りたいときは名前を渡します（例：`node tools/figs/all.js sp_figs`）。

必要なもの：`playwright`（node）と `Pillow`（python）。

## 流す前に必ず

**直したい内容を GitHub Pages に公開しておくこと。**

この道具は「公開しているURL」から撮ります。手元のファイルを `file://` で
開いて撮ると、**YouTube が動画を貸してくれず、説明パネルに
「エラー 153 動画プレーヤーの設定エラー」が写り込みます**。
2026-08-30 に実際にこれが起き、図4がエラー画面のまま公開されていました。

## つまずきやすいところ

| 症状 | 原因と直し方 |
|---|---|
| 動画のところが「エラー153」 | `file://` から撮っている。`設定.js` の `地図` が公開URLになっているか確認 |
| 動画のところに**広告**が写る | 通信を止めても防げない（広告も YouTube 自身の住所から来る）。動画が写る図では、枠の中の「スキップ」を押してから撮っている（`fig4_redo.js` の `広告を飛ばす`）。写り込んだら流し直す |
| 図の**大きさが変わってしまう** | `jpgにする.py` が、いま `docs/img` にある同じ名前の JPG の横幅に合わせている。新しい図は横幅が決められないので書き出さず、知らせる |
| 矢印が変なところを指す | 矢印の指す先は、その場で測って決めている。線の「まんなか」がパネルの裏だと候補ごと落ちるので、線の上を動かして見えている場所を探している（`fig4_redo.js`） |

## ファイルの役割

| ファイル | 撮るもの |
|---|---|
| `all.js` | 全部を順に流して、最後に JPG へ書き出す |
| `設定.js` | 撮る場所（公開URL）と書き出し先 |
| `make_figs.js` | パソコンの地図 `fig01`〜`fig07` |
| `fig4_redo.js` | `fig04`（動画が写るので撮り直す。広告を飛ばす） |
| `fig7_redo.js` | `fig07`（動画が写る） |
| `pc_figs.js` | パソコンのリクエスト・修正依頼 `pcadd1` `pcfix1` `pcfix2` |
| `mic_figs.js` | 「これなんて曲？」`pcmic1`〜`4` `spmic1`〜`4` |
| `sp_figs.js` / `sp_figs2.js` | スマホ `sp01`〜`sp14` |
| `kakunin_figs.js` | 申請の確認画面 `kakunin1`〜`4` |
| `chuu.js` | 図に枠・矢印・札を重ねる道具 |
| `mic_response.json` | 曲判定の返事の控え。撮り直すたびに外部サービスを叩かないため |
| `_out/` | 撮れた PNG の置き場（git には入れない） |

**`make_figs.js` のあとに `fig4_redo.js` `fig7_redo.js` を流す順番は変えないこと。**
この2枚は動画が写るため、あとから上書きしています。
