## 片づいたこと

### 2026-09-02

- **記録がサーバーの作り直しで消える件を解決**（ずっと保留だった「2番」）
  記録専用のリポジトリ `genre-roots-logs`（非公開）を保管庫にした。
  送る仕組み自体は前からあったが、保管庫がサーバー自身のリポジトリだったため
  「送るたびに Render が再起動する」という理由で止めてあった。
  分けたことで、何度送っても再起動しない。
  立ち上がりに保管庫から取り直すので、作り直されても前の記録が戻る。
  ※ アクセス統計だけでなく、**承認回数（trust.json）も毎回消えていた**。
    「3回承認したら10件枠」が作り直しのたびに0に戻っていたことになる。
    これも一緒に直った。
  ※ 鍵は fine-grained のため、新しいリポジトリを許可に足す必要があった
    （2026-09-02 チョロさんが対応）。/admin/health の log_repo で状態を見られる。

- **用語集の「ドロップC」「ドロップD」を直した**
  ギターの調弦名にEDMの「盛り上がる瞬間」の説明が当たっていた。
  用語集に2語を足して解決（Death Metal・Stoner Rock・Nu Metal の4か所）。

- **更新の記録のページを作った**（`docs/changes.html`）
  ジャンルの追加・修正を一件残らず載せる。全112件（追加64／修正35／
  動画の入れ替え13）。修正は「前」と「後」を並べて、書き換わった部分だけを
  抜き出して見せる。変更が入るたびに GitHub Actions が自動で作り直す。
  ※ これは「問い合わせ・修正依頼の通知が届かない」の言い換えだった。
    通知は要らない（依頼者が自分で承認する仕様なので）。必要だったのは
    「あとから何が変わったか追える場所」のほうだった。
