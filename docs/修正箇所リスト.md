`/admin/video_check/gemini_verify/replace/start` で差し替える。

### 2. リンクが1本しかないジャンル — 72件

マップ上でほぼ孤立して見える。不具合ではないが、関連の薄いジャンルが
多いという状態。Space Ambient、Underwater Ambient、Funky House、
Intelligent Techno、NRG Trance、Melodic EDM、Dark EDM、Heavy EDM、
Sovietwave、Neo-Psychedelia など。

### （旧3. 未登録のリンク先）— 2026年8月7日に対応不要と判断

Kizomba → `semba`、Nueva Cancion → `protest_song` のリンクが
承認時に除外されていた件。チョロさんの判断により、**この2つを
追加するための項目としては扱わない**。

理由と方針:

> 存在しないものに対して先にリンクを作成するという手順はない。
> 新規で出来上がった段階で、新規側からリンクを繋ぐ形になる。
> 新規追加を行う際も、既存のジャンルの中から関連付けを行うのが基本仕様。

この方針は genre_adder.py のプロンプト（新規登録・修正依頼の両方）に
明記済み（v1.92）。存在しないジャンルへ繋ごうとしないよう指示している。

## 完了したもの

### 用語説明の誤爆（2026年8月5〜6日）

見出しが短すぎる、あるいは日常語と同じ形の語が登録されていたため、
本文のあちこちに見当違いの説明が出ていた。

- 単語の途中への食い込み … 982箇所 → **0箇所**
- 日常語との衝突（「映像」にドビュッシーの曲集の説明） … **0箇所**
- 説明が5語未満のジャンル … 16件 → **0件**
- 用語の登録漏れ … 62件 → **0件**

削除した見出し: ラム / モー / ブルー / イズ / 17 / グラス / 140 / Gut / 映像

曲名が日常語と同じ形のものは、本文に原題を添えて区別できるようにした。
『映像（イマージュ）』『ブルー（Blue）』『イズ（Ys）』。

### マップが表示されなくなる不具合（2026年8月6日）

修正依頼の承認で、LINKS行がNODES配列に挿入され公開サイトが
真っ黒になった。書き込み前の検査に「実際にデータを読み込んで
描画が壊れないか確かめる」工程を追加し、同じ壊れ方は
確認画面に出る前に止まるようにした。

### メイン動画の重複（2026年8月6日）

同じ動画が複数ジャンルのメイン動画になっていた17組・36ジャンルを解消。
565ジャンルすべてが別々の動画になった。

検索語にジャンル名だけを使うと Minimalism がミニマル・ハウスに、
Romantic が恋愛のポップスに化けたため、カテゴリに応じた補助語を
足すようにした。

### 代表曲の動画の欠け（2026年8月6日）

代表曲は登録されているのに動画が入っていないジャンルが17件・21曲あった。
J-Fusionは4曲すべて動画なし。全件を補完した。

この過程で Ritual Ambient の代表曲の誤りも発覚。
「Fremde Zeit - Additium (Zero Kama)」と記載されていたが、
Fremde Zeit Additium はKlaus Schulzeの作品であり Zero Kama のものではない。
「The Secret Eye of L.A.Y.L.A.H.」に差し替えた。

## 確認に使うコマンド

    cd genre-roots-repo

    node tools/check_quality.js              本文の分量
    node tools/audit_wrong_tooltips.js       単語への食い込み
    node tools/audit_name_collisions.js      日常語との衝突
    node tools/audit_glossary_coverage.js    説明の行き渡り・登録漏れ
    node tools/find_missing.js --all         用語の登録漏れ（詳細）

書き込み前の安全確認（サーバー側が自動で呼ぶ）:

    node music_genre_finder/check_html_syntax.js <htmlのパス>

動画の確認（サーバー経由。YouTube検索の枠を使う操作に注意）:

    GET  /admin/video_check/duplicates/report   メイン動画の重複
    GET  /admin/video_check/tracks/report       代表曲の動画の欠け
    POST /admin/video_check/duplicates/start    重複の解消
    POST /admin/video_check/tracks/fill         代表曲の動画を補完
    POST /admin/video_check/replace_for         指定ジャンルの動画を探し直す
