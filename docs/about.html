最終更新：2026-08-31

どんなサイトか

音楽ジャンルルーツ辞典は、573の音楽ジャンルについて、 その成り立ち・親になったジャンル・影響を与えたジャンル・代表曲を1枚の地図にまとめた辞典です。 「自分の好きな音楽って、どこから来たんだろう」という素朴な疑問から作りはじめました。

作っているのはチョロ（chororinkob）という個人です。会社や団体ではありません。 使い方は使い方ガイドをご覧ください。

著作権について

このサイトの内容（ジャンルの説明文、用語の解説、地図の構成、図、画面のデザイン）は、 © 2026 チョロ に帰属します。無断複製・無断転載を禁じます。

とくに、まとめ方そのものが保護されます

個々の説明文だけではありません。どのジャンルを収録するか／どれとどれがつながっているか／ 知名度をどう評価するか／どの曲を代表曲とするか——この選び方と並べ方そのものが、 編集著作物・データベースの著作物として保護されます。

つまり、文章を書き換えたとしても、この地図の構造をそのまま写し取れば 権利の侵害にあたりえます。

許可なくできないこと

  • ジャンルのデータの全部または相当部分を、複製・転載・再配布すること
  • そのデータを、別のサイト・アプリ・データベース・機械学習用のデータセットに取り込むこと
  • 画面構成や文章を複製して、よく似たサイトを作ること

なお、このサイトを置いてある GitHub のリポジトリは、 GitHub Pages で公開するために公開設定にしています。中身を見られる状態ですが、 オープンソースのライセンスは一切付けていません。「見られる＝自由に使ってよい」ではありません。

出典を明記していただければ、著作権法上の引用の要件を満たす範囲での引用は歓迎します。 リンクを貼るのに許可は要りません。

出典と、第三者のもの

ジャンルの説明文

説明文は、このサイトのためにAIが下書きし、公開情報と照合して事実確認を行ったうえで掲載しています。 他のサイトから文章を写したものではありません。事実確認の手順は 使い方ガイドで説明しています。

動画

代表曲などの動画は、YouTube 公式の埋め込み機能で表示しています。動画ファイルを保存したり 再配布したりはしていません。各動画の権利は、それぞれの権利者に帰属します。

楽曲名・アーティスト名など

楽曲名・アーティスト名・レーベル名などの固有名詞は、それぞれの権利者に帰属します。 本サイトはそれらの権利者と関係のない、独立した個人のサイトです。

間違いを見つけられた場合は、説明パネルの「修正依頼」からお知らせください。 AIが調べて直す案を作り、その場でご自身で内容を確認して反映していただけます。 出典を添えていただけると、より正確に直せます。

記録している情報について

どのジャンルが読まれているかを知るため、また、いたずらによる費用の増大を防ぐために、 次の情報を記録しています。

  • 来訪者を見分けるための目印（ブラウザに保存される、意味を持たないランダムな文字列）
  • どのジャンルの説明を開いたか／どの曲を再生したか
  • IPアドレス（同じ回線からの申請が集中していないかを見るため）

お名前・メールアドレスをこちらから求めることはありません。 お問い合わせフォームでご記入いただいた場合のみ、お返事のために使います。 広告や第三者への提供には一切使いません。

IPアドレスは30日で削除しています。 ブラウザに保存された目印は、ブラウザの設定からいつでも消せます （消すと、次からは別の来訪者として数えられます）。
