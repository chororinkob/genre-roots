# 図の宿題

使い方ガイド（`docs/manual.html`）の図について、気づいたことを貯めておく場所。

**画面を直すたびに撮り直さない。**ここに書き足しておいて、手直しが落ち着いた
ところで、まとめて撮り直す。

```
node tools/figs/all.js
```

これで36枚がぜんぶ、そのときの画面に入れ替わる。使い方は `tools/figs/README.md`。

**流す前に、直した内容を公開しておくこと。**手元のファイルから撮ると
YouTube が動画を貸してくれず、図にエラーが写り込む。
