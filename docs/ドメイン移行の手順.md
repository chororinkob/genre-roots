# ドメイン移行の手順（genre-roots.com）

2026-09-01 決定。`chororinkob.github.io/genre-roots/` から
`genre-roots.com` へ移す。

**いきなり切り替えない。** 順番を間違えると、いま見に来ている人から
サイトが消える。下の順でやる。

---

## ⚠ いちばん大事な注意

**`CNAME` ファイルをリポジトリに置くのは、DNSの設定が終わってから。**

先に置くと、GitHub Pages は `chororinkob.github.io/genre-roots/` へのアクセスを
`genre-roots.com` へ転送し始める。ドメインがまだ向いていないと、
**転送先が存在せず、サイトが誰からも見られなくなる。**
いま友達が見ている状態なので、これは避ける。

---

## 手順

### 1. ドメインを買う（チョロさん）

- 業者：**Cloudflare Registrar** を推奨
  - $10.44/年（約1,600円）。原価売りなので**更新も同額**
  - WHOIS非公開（登録者の住所氏名を隠す）が無料
  - 日本の業者にありがちな「初年度1円・更新3,000円」が無い
- 条件：Cloudflare のネームサーバーを使うこと（GitHub Pages と問題なく併用できる）
- 買う前に、購入画面で `genre-roots.com` が本当に空いているか確かめる

### 2. DNS を設定する（チョロさん・Cloudflare の画面）

**A レコード**（`genre-roots.com` そのもの）を4つ。実測で確かめた値。

```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```

**AAAA レコード**（IPv6）も4つ入れておくとよい。

```
2606:50c0:8000::153
2606:50c0:8001::153
2606:50c0:8002::153
2606:50c0:8003::153
```

**CNAME レコード**（`www` から本家へ）

```
www  →  chororinkob.github.io
```

**プロキシは切る（グレーの雲にする）。** オレンジのままだと GitHub が
証明書を出せず、鍵マークが付かない。

### 3. サーバー（Render）を先に出す（クローディア）

`server.py` の「受け付ける相手」に `genre-roots.com` を足してある（2026-09-01）。
**これを先に公開しておかないと**、新しいドメインから
マイクの判定・ジャンル追加・修正依頼・記録が全部はねられる。

※ Render を出すとアクセスの記録が消える。「記録を消えない場所に置く」
作業を先に済ませておけば、失わずに済む。

### 4. CNAME ファイルを置く（クローディア）

DNS が効いているのを確かめてから、リポジトリの一番上に `CNAME` という
名前のファイルを作り、中身を1行だけ書く。

```
genre-roots.com
```

置いた時点で `chororinkob.github.io/genre-roots/` は新しいドメインへ
自動で転送されるようになる（前のURLを開いている人も飛ばされる）。

### 5. 鍵マーク（HTTPS）が付くのを待つ

GitHub が自動で証明書を用意する。数分〜1時間ほど。
リポジトリの設定画面で「Enforce HTTPS」に印を付ける。

### 6. 埋め込まれているURLを直す（クローディア）

`chororinkob.github.io` と書いてある場所が **約30か所**ある。
とくに大事なのは、共有したときに出る画像と説明（`og:url` `og:image`）。
ここが古いままだと、SNSに貼ったときに前のURLが出る。

| ファイル | 数 |
|---|---|
| `genre_roots.html` | 5 |
| `docs/about.html` | 5 |
| `index.html` | 4 |
| `docs/manual.html` | 4 |
| `music_genre_finder/templates/contact.html` | 3 |
| `music_genre_finder/templates/admin_pending_list.html` | 3 |
| その他（道具・仕様書など） | 数か所 |

**置き場所が変わることに注意。** いまは `/genre-roots/` という階層の下に
あるが、独自ドメインでは一番上に来る。

```
前： chororinkob.github.io/genre-roots/genre_roots.html
後： genre-roots.com/genre_roots.html
```

### 7. 確かめる（クローディア）

- 新しいURLで地図・ガイド・「このサイトについて」が開くか
- 鍵マークが付いているか
- マイク・ジャンル追加・修正依頼が動くか（CORSが通っているか）
- 共有したときの画像と説明が新しいURLになっているか
- 前のURLから転送されるか

### 8. 検索のことは急がない

Google に新しいURLを覚え直してもらうには数週間かかる。
転送さえ効いていれば評価は引き継がれるので、待てばよい。
